# 微信公众号踩坑手册（模板星球）

本仓库发公众号模板文时必须遵守。目标：少限流、可复制进编辑器、读者体验稳定。

## 发布前检查清单

- [ ] 标题/摘要/文首/页脚无「留言领取、私信发你、免费无套路、网盘链接、二维码」
- [ ] 正文可独立读完（示例文完整），不像残篇外跳
- [ ] 声明只做「展示 + 欢迎交流」，不承诺交付通道
- [ ] 用词统一「模板」（不用「模版」）
- [ ] `body` 白底；外层容器无左右 padding（微信自带边距）
- [ ] 浏览器渲染后再复制富文本；勿贴纯 HTML 源码指望外链 CSS

---

## 一、合规与限流（最高优先级）

### 已踩实锤

后台曾判定：**不良信息 → 导流内容**。

高危文案（禁止出现在标题、摘要、正文声明、页脚、精选留言）：

| 禁止 | 原因 |
|------|------|
| 评论区留言 + 我私信发你 | 互动导流 |
| 免费 / 无套路 / 留言即可领 | 营销 + 导流感 |
| 文内网盘链接、领取二维码 | 内容导流（第三方） |
| 欢迎转发（硬引导） | 接近诱导分享 |

### 个人号现实约束

- 微信小店常不支持个人主体 → 不能默认「走小店」
- 完整模板文件往往只能网盘交付 → **不要写进正文**
- 推荐路径：正文只展示 → 读者**主动**发消息给公众号 → 自动回复/人工回网盘

### 合规声明（推荐）

```text
下面是「××」××模板的排版效果展示，欢迎交流。
```

可要可不要「先说一声」标题；短声明时去掉更干净。

### 页脚

- ✅ `感谢阅读 · 下次见`
- ❌ `欢迎转发 · 保持更新`

### 已发文章改不动时

1. 导流话术硬的旧文：能删则删，再发合规新版（示例正文也要换，防重复）
2. 标题若只允许改约 3 字：优先把 `领取`→`展示` 或 `参考`
3. 精选留言勿置顶领取话术
4. 限流期少发同质模板硬广文

### 限流恢复

无固定天数；常见轻度约数天到两周。以后台通知期限为准。限流期先发正常内容养号。

## 二、标题与摘要

### 推荐系列格式

```text
公众号模板分享｜【模板名 · 类型】价值点
```

例：

```text
公众号模板分享｜【赭笺 · 随笔版】温暖排版，让文字更好读
公众号模板分享｜【青笺 · 叙事版】雅致版式，拉高文章格调
公众号模板分享｜【蓝笺 · 宣发版】清晰结构，适合产品表达
公众号模板分享｜【语笺 · 对话版】左问右答，对谈更有现场感
公众号模板分享｜【杏笺 · 清单模板】对照分明，步骤更好读
```

### 风险控制

- 「分享」单独用通常可接受；刚限流可改成「展示 / 示例」
- 后半句轮换，避免每篇同一句式
- 中间穿插非模板文（写作/排版心得），降低纯营销号感
- 摘要写「版式参考 / 效果展示」，勿写领取

### 摘要示例

```text
公众号随笔怎么排更好看？「赭笺」给你一版温暖柔和的版式参考，结构清晰，读起来舒服。
```

更稳可把「给你一版」改成「这是一版」。

## 三、HTML / CSS（复制进微信）

### 工作流（本仓库实测）

1. 样式放 `style.css`，HTML 用 class
2. 浏览器打开渲染页 → 全选复制富文本 → 粘贴公众号编辑器
3. 等 CSS 加载完再复制

### 布局

| 方案 | 手机横排 | PC 边框 | 结论 |
|------|----------|---------|------|
| `inline-block`（仅 class） | 易竖排 | — | 外链 CSS 常被吃 |
| `float` | 易竖排 | 无表框 | 不可靠 |
| `table` 三列 | 稳 | PC 易出灰线 | **数据条优先 table**；边框尽量 `border:0` + 底色同色 |

顶部色条：优先单层 `linear-gradient`，避免双段 `inline-block`/table 错位。

### 颜色与圆角

- 用**实色 hex**，少用 CSS 变量（复制后 PC 端更稳）
- `body` / 正文容器：`#ffffff`，避免灰米色外框 vs 微信白边割裂
- 色块 `border-radius: 8px` 时，左侧 `border-left` 色条两端会带圆；需要圆角就四角统一，需要左侧直角用 `0 8px 8px 0`

### 间距

- 外层 section：**不要**左右 padding（微信已有边距）
- 有色底的 notice：保留左右内边距，避免字贴色边

### 标签

浅底 + 彩色字（如 `#d8ecf7` + `#0f5c8c`）。深底白字在微信里白字易丢，变成看不清。

## 四、模板系列约定

| 名称 | 用途 | 主色印象 |
|------|------|----------|
| 赭笺 | 生活随笔 | 暖赭 `#c45c26` |
| 青笺 | 叙事长文 | 鼠尾绿 |
| 蓝笺 | 产品宣发 | 深海蓝 `#0f5c8c` |
| 语笺 | 对话 / 访谈 / 段子 | 青墨左气泡 + 茶褐右气泡；左右对齐用 table |
| 杏笺 | 方法/科普干货（正误对照 + 分步做法） | 丹红 `#8b3a3a` + 浅金 `#c4a06a` |

用词：**模板**（规范写法）。

删旧重发时：换示例正文 + 换标题，降低重复率。

---

## 五、Agent 行为要求

编写或修改本仓库公众号相关 HTML/文案时：

1. 先过「发布前检查清单」
2. 不主动加入领取/私信/网盘/转发诱导
3. 改 notice、标题、摘要前，默认按限流后的软口径
4. 三列数据区默认 table；顶部色条默认渐变
5. 样式优先 CSS 文件 + 浏览器富文本复制说明，而不是为微信手写全量内联（除非用户明确要求）
